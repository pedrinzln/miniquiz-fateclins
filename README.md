# 🎯 QuizLab — Mini Quiz de Conhecimentos Gerais

O **QuizLab** é um jogo de perguntas e respostas desenvolvido com HTML, CSS e JavaScript, com o objetivo de tornar o aprendizado mais divertido e interativo.

O jogador responde a perguntas de conhecimentos gerais contra o tempo, acumula pontos e pode tentar superar seu próprio recorde.

## ✨ Funcionalidades

* 🧠 Perguntas de conhecimentos gerais.
* ⏱️ Cronômetro para cada pergunta.
* ⭐ Sistema de pontuação.
* 📊 Barra de progresso durante a partida.
* ✅ Feedback imediato para respostas corretas e incorretas.
* 🏆 Registro do recorde pessoal.
* 👤 Identificação do jogador pelo nome.
* 🎨 Interface moderna com tema escuro.
* 🌌 Fundo animado com partículas interativas que reagem ao mouse.
* ☁️ Integração com Supabase para salvar pontuações no ranking.

## 🛠️ Tecnologias utilizadas

* **HTML5** — estrutura da aplicação.
* **CSS3** — estilização, animações e efeitos visuais.
* **JavaScript** — lógica do jogo, perguntas, cronômetro e pontuação.
* **Bootstrap 5** — componentes e responsividade.
* **Supabase** — banco de dados e armazenamento do ranking.

## 🎮 Como jogar

1. Acesse o QuizLab pelo navegador.
2. Digite seu nome.
3. Clique em **Começar quiz**.
4. Responda às 10 perguntas antes que o tempo termine.
5. Confira sua pontuação ao final.
6. Jogue novamente para tentar bater seu recorde!


## 🎯 Objetivo do projeto

O QuizLab foi desenvolvido como um projeto de apresentação para visita de escola municipal na faculdade Fatec Lins, localizado na cidade de Lins/SP.
